# A-Share Data icon

The icon combines market candlesticks with a structured data tray:

- the candlesticks represent price and market movement;
- the lower tray represents normalized, queryable data rather than trading execution;
- teal distinguishes read-only financial data from buy/sell or brokerage products.

Do not replace it with currency symbols, a generic upward arrow, or a brokerage logo. This plugin
retrieves sourced market data and does not promise returns or place orders.
