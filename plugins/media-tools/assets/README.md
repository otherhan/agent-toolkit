# Media Tools icon

The icon represents the plugin's actual workflow:

- the large film frame is the source MP4/MOV/M4V file;
- the smaller foreground frame is the normalized H.264/AAC output;
- the diagonal arrow communicates compression and conversion from source to output.

Do not replace it with generic image, audio, magic-wand, or checkmark symbols unless the plugin gains those capabilities.

`icon.svg` is the light-interface asset and `icon-dark.svg` is the dark-interface asset. Teal is secondary branding; the frame-to-frame transformation carries the functional meaning.
